Jak to pouzit

Nejlepsi vysledek dostanes, kdyz spojíš mod, kontext, cil a format vystupu.

1. Vyber mod

Napriklad: Truth mode + Short mode. Mod urci ton, hloubku a styl odpovedi.

2. Pridej kontext

Napis, co delas, pro koho to je, co uz vis a co je omezeni. Kontext setri mnoho oprav.

3. Urc vystup

Rekni, jestli chces tabulku, checklist, email, kod, rozhodnuti, osnovu nebo konkretni kroky.

Katalog modu

Hledej podle nazvu, popisu nebo kategorie. Tlacitko u karty zkopiruje kratky zacatek promptu.

Vyrazy, ktere zlepsuji zadani

Tyto formulace pomahaji AI pochopit cíl, hranice a ocekavany vystup.

Hotove sablony promptu

Zkopiruj si strukturu a vypln hranate zavorky podle situace.

Silne kombinace modu

Kombinace jsou casto lepsi nez jeden mod, protoze oddeli styl, roli a format.

Rychle rozhodnuti

Decision mode + Truth mode + Checklist mode: Mam [situace]. Porovnej moznosti, rekni nejlepsi volbu a pridej rizika.

Uceni od nuly

Beginner mode + Teacher mode + Examples mode: Vysvetli mi [tema] jednoduse, s priklady a kratkym testem na konci.

Kvalitni kritika

Critic mode + Devil's advocate mode + No-fluff mode: Zhodnot [napad/text/kod]. Hledej slabiny, rizika a konkretni opravy.

Prace s textem

Rewrite mode + Tone mode + Clarity mode: Prepis text pro [publikum], ton [ton], zachovej vyznam a zkrat o 30 %.

Kod a debugging

Debug mode + Senior engineer mode + Step-by-step mode: Najdi pricinu chyby v [kod/log], navrhni opravu a pridej testy.

Strategie a byznys

Strategy mode + Business mode + Risk mode: Navrhni strategii pro [cil], priority, metriky, rizika a dalsi kroky.

Tip: Pokud chces presnou odpoved, pridej vetu: „Kdyz chybi dulezite informace, nejdriv se zeptej maximalne na 3 upresnujici otazky.“ Tim snizis pocet spatnych predpokladu.
